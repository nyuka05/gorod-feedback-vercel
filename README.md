# Сервис сбора обратной связи

Веб-площадка финальных питчингов Школы городских продюсеров. Участники и организаторы выбирают своё имя, ставят выступлению от 1 до 10 лайков и при желании оставляют сообщение. Повторная отправка от того же человека тому же участнику обновляет существующую запись, не меняя её исходную дату.

## Возможности

- 19 стартовых участников и несколько независимых организаторов;
- видимые текущие суммы лайков и публичные доски сообщений;
- административная панель `/admin`;
- добавление, редактирование, деактивация и удаление людей;
- импорт списков из XLSX, XLS или CSV;
- загрузка фотографий в R2;
- ручное открытие и закрытие приёма обратной связи;
- таблица итогов, выгрузка XLSX и сброс тестовых отзывов;
- адаптивный интерфейс для телефона и компьютера.

## Локальный запуск

Нужен Node.js 22.13 или новее.

```bash
pnpm install
pnpm dev
```

Адрес по умолчанию — `http://localhost:3000`. В локальной среде пароль администратора — `admin`. Для размещённой версии обязательно задаются `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`.

## Проверка

```bash
pnpm test
pnpm lint
pnpm build
```

Схема D1 хранится в `db/schema.ts`, миграции — в `drizzle/`. Привязки Cloudflare объявлены в `.openai/hosting.json`: база `DB` и хранилище фотографий `UPLOADS`.
