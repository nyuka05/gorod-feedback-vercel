# Сервис сбора обратной связи — версия для Vercel

Веб-площадка для оценки выступлений: участники и организаторы выбирают своё имя, ставят от 1 до 10 сердечек и при желании оставляют сообщение. Повторная отправка от того же отправителя тому же участнику обновляет голос, сохраняя первоначальную дату создания.

## Технологии

- Next.js 16 и React 19;
- Turso/libSQL для участников, организаторов, голосов, сообщений и настроек;
- Drizzle для описания SQLite-схемы;
- Vercel для сборки и публикации.

## Быстрый локальный запуск

1. Создайте `.env.local` по образцу `.env.example` или выполните `pnpm dlx vercel env pull .env.local` после подключения проекта Vercel.
2. Установите зависимости: `pnpm install`.
3. Примените миграции: `pnpm db:migrate`.
4. Запустите сайт: `pnpm dev`.
5. Откройте `http://localhost:3000`.

Для локального запуска также можно использовать `start-local.ps1`.
