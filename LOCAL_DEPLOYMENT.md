# Размещение площадки на своём ПК

## Рекомендуемый вариант

Для настоящего мероприятия надёжнее использовать уже опубликованную версию:

`https://gorod-feedback-final.nyuka05.chatgpt.site`

Она работает независимо от домашнего ПК, Wi-Fi и отключения электричества. Локальный запуск полезен для репетиции, автономной площадки внутри одной сети или хранения отдельной локальной базы.

## Запуск на компьютере

1. Установите Node.js 22.13 или новее.
2. Нажмите правой кнопкой на `start-local.ps1` и выберите «Выполнить с помощью PowerShell».
3. При первом запуске скрипт установит зависимости, создаст случайный пароль администратора и покажет адреса.
4. Оставьте окно PowerShell открытым до конца голосования.

На этом компьютере сайт открывается по адресу `http://localhost:3000`. Люди, подключённые к той же Wi-Fi сети, используют адрес вида `http://192.168.1.25:3000`, который покажет скрипт.

Если Windows спросит разрешение для брандмауэра, разрешите доступ только для частных сетей.

## Временная ссылка через интернет

1. Установите `cloudflared` с официальной страницы Cloudflare.
2. Запустите `start-local.ps1` и не закрывайте его.
3. Во втором окне PowerShell запустите `start-public-link.ps1`.
4. Скопируйте появившуюся ссылку `https://…trycloudflare.com` и отправьте участникам.

Такая ссылка меняется после каждого запуска и предназначена для тестирования. Для постоянного адреса нужен именованный Cloudflare Tunnel и собственный домен либо уже опубликованная версия Sites.

## Важные условия

- Компьютер не должен переходить в сон или выключаться.
- Оба окна PowerShell должны оставаться открытыми.
- Файл `.env.local` содержит пароль администратора и не должен передаваться другим людям.
- Локальная база находится в служебной папке `.wrangler`; перед переносом или переустановкой её нужно сохранить.
- Пользователи не авторизуются: человек со ссылкой выбирает имя из списка, поэтому действует принятое организационное правило.
