# Локальный запуск Vercel-версии

Локально запускается тот же стандартный Next.js-проект, который публикуется на Vercel. Голоса и сообщения при этом всё равно записываются в Turso, поэтому компьютеру нужен доступ в интернет.

## Подготовка

1. Установите Node.js 22.13 или новее.
2. Выполните подключение проекта и загрузите переменные окружения:

```powershell
pnpm dlx vercel login
pnpm dlx vercel link
pnpm dlx vercel env pull .env.local
pnpm db:migrate
```

3. Убедитесь, что `.env.local` содержит `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ADMIN_PASSWORD` и `ADMIN_SESSION_SECRET`. Не передавайте этот файл другим людям.

## Запуск

Нажмите правой кнопкой на `start-local.ps1` и выберите «Выполнить с помощью PowerShell». Скрипт покажет адрес для этого компьютера и адрес для устройств в той же сети Wi-Fi.

Если Windows спросит разрешение брандмауэра, разрешите доступ только для частных сетей. Окно PowerShell должно оставаться открытым.

Для временной ссылки через интернет можно во втором окне запустить `start-public-link.ps1`. Это вспомогательный вариант для проверки; основная публичная версия должна работать на Vercel.

Полная инструкция: [VERCEL_DEPLOYMENT.md](./VERCEL_DEPLOYMENT.md).
